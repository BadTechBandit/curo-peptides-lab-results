# Curo peptides: lot-by-lot lab results

This repository holds the lab results for each research peptide lot that [Curo](https://curo.you) lists in its public [COA library](https://curo.you/coa). Each row is one production lot. It gives the testing lab, the report date, the identity result, HPLC purity and the measured fill, with links to the full report and to the product page.

- Curo home: https://curo.you
- Product catalog: https://curo.you/product-catalog
- COA library with every lot report: https://curo.you/coa
- How Curo tests every lot: https://curo.you/testing

The data was last checked against curo.you/coa on 2026-10-14.

## Files

- `data/curo-lots.csv` has one row per lot.
- `data/curo-lots.json` has the same rows, plus the source page and the date it was read.

Bacteriostatic water lots are on curo.you/coa but are not in this dataset.

## Columns

| Column | Meaning |
|---|---|
| `product`, `dose` | Product name and label amount, as listed on curo.you |
| `lot` | Lot number printed on the vial label |
| `lot_status` | `current` or `previous`, as shown on curo.you/coa |
| `lab` | Independent lab that ran the test |
| `report_date` | Date on the lab report (YYYY-MM-DD) |
| `identity` | The lab's identity result for the compound |
| `hplc_purity_percent` | Purity by HPLC, as percent peak area |
| `measured_fill` | Amount per vial that the lab measured |
| `fill_percent_of_label` | Measured fill as a percent of the label amount |
| `coa_pdf_url` | Report PDF on curo.you (empty when the report is only on the lab's site) |
| `lab_verify_url` | The same report on the testing lab's own site |
| `product_url` | Product page on curo.you |
| `coa_page_url` | This lot's row on curo.you/coa |

## Check a vial

1. Find the lot number on the vial label.
2. Find that lot in the table above or on [curo.you/coa](https://curo.you/coa).
3. Open the lab verify link and compare the compound and the fill with the vial in your hand.
